· Where npm caches the packages of palette installs. On the storage (default) an install

                            Nach einem Update von RedMatic werden die Nodes RedMatic-HomeKit und RedMatic-Matter auf ihre
                            neueste passende Version gebracht, sofern sie installiert sind, und Node-RED startet danach
                            einmal neu. Andere Nodes bleiben, wie sie sind, ebenso ein Paket, für das in der
                            package.json des Node-RED-Verzeichnisses eine feste Version steht. Ohne Verbindung
                            zur npm-Registry bleibt alles beim Alten, der nächste Start von RedMatic versucht es erneut.
                            
· After an update of RedMatic, the nodes RedMatic-HomeKit and RedMatic-Matter are brought
                            to their newest matching version, if they are installed, and Node-RED then restarts once. Other
                            nodes stay as they are, as does a package with an exact version in the package.json
                            of the Node-RED directory. Without a connection to the npm registry nothing changes, and the
                            next start of RedMatic tries again.

                            Schreibintervall in Sekunden: so lange sammelt Node-RED Änderungen im Speicher, bevor es sie in die
                            Datei schreibt. Ein längeres Intervall schont die SD-Karte, bei einem Stromausfall gehen aber die
                            Änderungen seit dem letzten Schreiben verloren. Beim Stoppen von Node-RED wird immer geschrieben,
                            und ein Context, dessen Werte sich nicht geändert haben, wird nicht neu geschrieben.
                            
· Write interval in seconds: how long Node-RED collects changes in memory before it writes
                            them to the file. A longer interval spares the SD card, but a power loss loses the changes since
                            the last write. Node-RED always writes when it stops, and a context whose values did not change is not rewritten.
